# 山货与蘑菇识别交易平台

基于深度学习 CNN 与 Django 的山货识别、蘑菇有毒识别和交易管理平台。

## 项目定位

本仓库是从本地原始项目中整理出的 GitHub 清理版，保留核心源码、配置模板和必要说明；训练数据、数据库、模型权重、日志、账号信息、压缩包和竞赛报名材料等内容未纳入仓库。

## 技术栈

Python、Django、CNN、图像识别、电商交易、数据管理

## 功能模块

- 山货/蘑菇图片识别
- 有毒风险判断
- 商品发布与交易
- 用户管理
- 后台管理
